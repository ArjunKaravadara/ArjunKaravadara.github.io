# Arjun Karavadara — Portfolio (GitHub Pages bundle)

Self-contained static export of the portfolio site. Everything is local:
`index.html` + `assets/` (images, videos, bundled fonts). No build step,
no server, no external CSS/JS — Google Drive video links, WhatsApp and
social links work exactly as on the live site.

## Deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `portfolio`).
2. Upload ALL files from this folder (keep the `assets/` folder structure
   exactly as-is — paths are relative).
3. In the repo: **Settings -> Pages -> Build and deployment -> Source:
   Deploy from a branch**, pick `main` / `(root)`, Save.
4. Your site goes live at `https://<your-username>.github.io/portfolio/`
   within a minute or two.

Tip: for a custom domain, add it under Settings -> Pages -> Custom domain.
